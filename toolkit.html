What Tool Might Help with This Task?

Investigate tools for study, source discovery, writing support and reference management. Choose by learning purpose, risk and the rules for your assessment.

Product information last checked: 17 September 2026. Features and account arrangements can change; check current provider documentation for your account.

Check assessment permission, disclosure and privacy before use. AI can suggest what to investigate; it is not your academic evidence. Follow the detailed verification guide. General platform access links are on AI Platforms.

Featured Student Tools

Gemini Notebook (formerly NotebookLM)

For permitted work with selected sources, investigate Gemini Notebook. Source grounding can make claims easier to trace and check, but does not guarantee interpretation, accuracy, privacy or assessment permission. See the tutorial.

Check current details: product features, pricing, model access and privacy settings change frequently. Treat the tools listed here as examples and check current provider documentation before relying on a feature for assessed work.

Possible Study Tasks

  • Grounded Responses: Where citations are provided, read the original passage and check whether it supports the claim.
  • Study Materials: Check available outputs for your account and review any proposed guide, timeline or FAQ against selected readings.
  • Focused Notebooks: Select relevant sources and consider what is missing; a limited source set cannot establish what an entire field says.
  • Transparent Outputs: Trace important claims to source material; do not assume every output is fully supported.

Options to Check

  • Check supported source formats and ways to question permitted material.
  • Check currently available study outputs rather than relying on a fixed feature list.
  • If an audio overview is available, use it for orientation and check its important claims against the originals.

Choosing a Gemini Notebook Account

Capacity

Check the current limits for notebooks, sources, chat use and audio overviews. These limits change more often than study habits do.

Privacy and account type

A personal account, institution-approved account and paid workspace can have different controls. Check before uploading assessed, unpublished or personal material.

Sharing and collaboration

Before group work, confirm whether sharing, access control and usage visibility match your module rules and group agreement.

Output controls

Features such as summary style, length and export options may vary. Treat outputs as study aids, then verify them against the cited source passages.

Google AI Studio

Investigate Google AI Studio for prompt experiments. Check current supported inputs, outputs and account terms before use; do not assume that a particular model or feature is available.

Possible Tasks to Investigate

  • Text Tasks: Investigate questions about permitted notes, comparisons between explanations and prompt experiments.
  • Multimodal Capabilities: Check which input formats and analysis options are currently supported on your account.
  • Code Tasks: If permitted and supported, investigate code examples and explanations that you then inspect, run and understand yourself.

Account and Data Checks

Before Uploading

Free and experimental AI services can have different data settings from institution-approved services. Do not input sensitive, confidential or personal data unless you have checked the current terms and your institution allows it.

Check Institutional Controls

For anything beyond public, low-risk study material, use an institution-approved account or a properly governed service and check the current retention, review and training settings.

Citation & Discovery Tools

Investigate source discovery and reference management alongside your library databases. Check current features and pricing; read original sources before using them as evidence.

Research Discovery

  • Connected Papers — investigate connections between candidate papers
  • ResearchRabbit — explore citation connections and evaluate original papers
  • Elicit — investigate candidate papers; check any summaries against originals
  • Consensus — investigate relevant studies; read originals to check claim support

References & Citations

  • Zotero — investigate reference management; check captured metadata
  • Mendeley — investigate reference management; check current features
  • Paperpile — investigate reference management; check application requirements
  • Google Scholar — quick look-ups; verify metadata/DOIs
Check metadata (authors, year, DOI) against the original or publisher page, and read the source to check that it supports your claim before citing it.

Privacy and Local-Model Options to Investigate

Investigate current privacy terms and configured data flows when choosing an access route. Provider descriptions, local operation or payment do not authorise sensitive uploads or establish reliable answers.

Web Services to Check

  • Duck.ai — check current provider privacy and account information
  • Lumo — check Proton's current terms for this assistant
  • Brave Leo — check browser settings and current provider privacy terms
  • Okara — check current storage, access and training arrangements

Local and Self-Hosted Tools

  • LM Studio — investigate local model use and device requirements
  • Ollama — investigate local model setup and configured connections
  • Jan — investigate local or API-connected model use
  • GPT4All — investigate local model use and configured data flows
Check whether the configured tool uses a local model, a remote API or additional online services. Check licence terms and every important claim; local operation alone does not establish accuracy or permission.
